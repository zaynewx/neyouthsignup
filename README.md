## Deploy to Vercel

1. Download and extract this ZIP.
2. Create a new GitHub repository.
3. Upload all extracted files and folders to the repo root.
4. In Vercel, click **Add New Project** and import the GitHub repo.
5. Vercel should auto-detect the app.

Use these settings if prompted:
- Framework Preset: Vite
- Build Command: `npm run build`
- Output Directory: `dist`

## Run locally

```bash
npm install
npm run dev
```
